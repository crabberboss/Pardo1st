# 帕朵一号双端更新公告

适用范围：Windows 桌面端 2.9.17 → 2.9.25、Android 端 0.4.6 → 0.4.21。

- 阅读与导入：完善 TXT、Markdown、EPUB 导入；双端阅读模式支持进度记忆、目录、上下滑动和左右翻页、排版与主题调整，并可浏览 EPUB 插图。阅读时可直接进入本章改写。
- 知识库：章节切分、原文编辑、结构化总结、普通关键词与特殊场景标签继续保留；新增可选的原文向量索引。结构化记忆和原文索引可按章续建，对话检索同时参考关键词、章节记忆与原文片段。
- 对话与模型：改善角色扮演和聊天存档操作，增加可选联网搜索、图片输入与模型选择；双端扩充 Gemini、GLM 等渠道，调整输出额度及推理模型的错误提示。
- 小说生成：双端提供项目设定、章节细纲、正文生成和角色／事件记忆；支持保存、续建、修改及重新生成已完成章节。剧情规划接口仍为预留项，不代表该功能已接入。
- 改写与文件互通：改写提示词、模板、章节原文和结果的管理更完整；增加统一导入导出入口。知识库 v5 文件可携带原文向量索引，但不携带 API 密钥。
- 界面与稳定性：优化桌面端生成工作区、导入导出排版和聊天可读性；完善手机端返回操作、阅读菜单及后台任务状态；修复背景设置无法持久化等问题。

本分享包不含用户的知识库、小说原文、对话存档、API 密钥或个人设置。安卓端虽已通过构建与自动测试，发布前仍建议在实际手机上验证主要流程。
