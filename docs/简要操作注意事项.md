# 简要操作注意事项

1. Windows 版解压后运行 EXE；Android 版安装 APK。首次使用请自行配置 API 渠道与模型，并先执行连接测试。不要把自己的知识库导出文件、密钥或带个人数据的 `data` 目录一起转发。
2. 导入与章节切分在本机进行；章节总结、提示词扩写、对话、小说生成及改写在选择在线渠道时会发送相应内容到服务商。联网搜索也可能使用第三方服务。实际收费取决于所用渠道、模型和服务商规则，请查看自己的账单与额度。
3. 长篇小说建议先试运行少量章节，确认模型输出、单章耗时和费用后再全库生成。在线原文向量化会上传原文片段并可能产生大量嵌入请求；不需要语义检索时可关闭该选项。向量化不是把整库一次性塞进聊天模型。
4. 本地模型通常不产生在线 API 费用，但长章节生成、重写及本地向量化会占用 CPU、内存、显卡和磁盘。手机上长时间任务可能发热、耗电，请保持足够电量与存储空间；设备休眠或系统限制后台活动时，返回应用核对任务状态。
5. 不同嵌入模型生成的向量通常不能直接混用。跨设备导入知识库后，若原嵌入渠道或模型不可用，请在目标设备重新建立向量索引；结构化章节记忆仍可使用。聊天模型可以更换，检索由软件完成。
6. 分享包不含 Windows WebView2 或其他系统运行环境。如桌面窗口无法打开，请先检查系统是否安装 WebView2。安卓 APK 使用与上一测试包相同的调试签名；若设备提示签名冲突，请先备份应用内数据，再处理旧安装。
